# Emacs Packages

A selection of emacs packages used in my configuration.

* [org-snooze](org-snooze.el): reschedule entries upon keyword change in org-mode.
* [org-rescheduler](org-rescheduler.el): removes timestamps when repeating.
* [pilish-bang](pilish/pilish-bang.el): optional extension for [dnouri/pilish](https://github.com/dnouri/pilish) (install pilish separately) that adds `!`/`!!` shell command support to the input buffer purely via `advice-add`, with no changes to pilish's own files. Load with `(require 'pilish-bang)` after pilish.
